# 規模・複雑度の系列表

`/audit_scale`（`scripts/observe-scale.sh`）で測った値を 1 回 1 列で並べる。手順・判定は `docs/maintenance.md`「health」、その回の所見は `docs/progress/<日付>-health-*-report.md`（**ここには所見を書かない**）。

- 値はすべて `scripts/observe-scale.sh` の `== COUNTS ==` の逐語。`-1` は「測れなかった」で、0 件とは別。
- 物差し: ソースだけを読む（ビルド・テストは回さない）。対象は git が管理するファイルから、取得した上流（`.upstream/`）・依存・ビルド成果物・`web/public/`（生成した配信データ）を除いたもの。
- 試験の数は**静的に数えた**関数・ケースの数（`it.each` の展開や E2E の 2 つの project は数えない）。実行した件数は報告の `EXIT=` と件数を見る。
- 列は新しいものを右に足す。8 列を超えたら、公開時点の列（基準）を残して古い列から消す（消した列は git の履歴に残る）。
