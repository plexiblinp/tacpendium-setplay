# CONTRIBUTING

English follows Japanese.

## 日本語

- **意見・不具合・翻訳の改善**は歓迎します。窓口は 2 つです。
  - Google フォーム（ログイン不要。サイトの画面のリンクから）
  - GitHub の Issues（公開されるので、個人情報は書かないでください）
- **Pull Request は受け付けていません**（少人数で速く作るため）。直してほしい点は Issue かフォームでお知らせください。
- **フレームデータの誤り**は、データの取込元である公開版 Tacpendium の窓口（`NOTICE` の連絡先）へお願いします。このリポジトリのデータは、そこから取り込んでいます。
- **セキュリティ上の問題**は Issue に書かず、`SECURITY.md` の方法で知らせてください。
- 送られた文やコードを取り込む場合は、取り込む先と同じライセンスで受け取ります（アプリは AGPL-3.0-or-later、データは CC-BY-SA-4.0、開発の文書・道具は MIT。どこが何かは `REUSE.toml`）。
- 新しいキャラクターには、ゲームでの配信開始から 2 週間後に対応します（`README.md`）。それより前の対応の依頼にはお応えしません。

## English

- **Feedback, bug reports and translation improvements** are welcome, through either:
  - the Google Form (no sign-in needed; linked from the site), or
  - GitHub Issues (public, so please do not include personal information).
- **Pull requests are not accepted** (to keep a small project moving fast). Please describe what you would like changed in an issue or the form.
- **Errors in frame data** should go to the public Tacpendium project this data is imported from (contact in `NOTICE`).
- **Security problems** must not be filed as issues; see `SECURITY.md`.
- Anything you send that we incorporate is received under the same license as the part it goes into (app: AGPL-3.0-or-later, data: CC-BY-SA-4.0, development docs and tools: MIT; see `REUSE.toml`).
- New characters are supported 2 weeks after their in-game release (see `README.md`); requests for earlier support will not be acted on.
