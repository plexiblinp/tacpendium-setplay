# SECURITY

English follows Japanese.

## 日本語

- 脆弱性を見つけたら、**公開の Issue には書かず**、GitHub の「Report a vulnerability」（このリポジトリの Security タブ。private vulnerability reporting）から知らせてください。内容は開発者にだけ届きます。
- 対象は、このリポジトリのコードと、公開しているサイト（静的な配信と `/api` の Worker）です。
- 個人が運営する無償のサイトのため、返事や修正の期限はお約束できません。報奨金はありません。
- サイトへの負荷試験・大量の要求・他人のデータへのアクセスを試すことはやめてください。

## English

- If you find a vulnerability, **do not open a public issue**. Report it through GitHub's "Report a vulnerability" (Security tab of this repository; private vulnerability reporting). Only the developer can see it.
- In scope: the code in this repository and the public site (static delivery and the `/api` Worker).
- This is a free site run by an individual, so no response or fix deadlines can be promised, and there is no bug bounty.
- Please do not load-test the site, send large volumes of requests, or try to access other people's data.
